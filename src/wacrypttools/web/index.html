Instalar no computador
Antes de copiar: verifique se há espaço suficiente no computador. O backup ocupa o mesmo tamanho que os arquivos no pendrive. Abra o Explorador de Arquivos e veja o espaço livre no disco C:.
  1. Abra o Explorador de Arquivos (pasta amarela na barra de tarefas)
  2. No painel esquerdo, clique no nome do pendrive para abrir apenas ele
  3. Selecione todos os arquivos e pastas dentro do pendrive (Ctrl+A)
  4. Copie (Ctrl+C)
  5. Abra a pasta Documentos. Se já existir uma pasta Backup WhatsApp lá, apague-a primeiro para não sobrar arquivos antigos. Depois crie a pasta novamente e cole (Ctrl+V) — não cole diretamente na área de trabalho, pois o backup pode ter vários GB
  6. Quando terminar de copiar, entre na pasta e clique duas vezes em index.html
  7. Para criar um atalho na área de trabalho: clique com o botão direito em index.html → Enviar para → Área de trabalho (criar atalho)
Opção avançada: instalar automaticamente com script

Atenção: por ser um arquivo baixado, o Windows pode bloqueá-lo. Antes de executar: clique com o botão direito no arquivo baixado → Propriedades → marque Desbloquear → OK. Só então dê dois cliques para rodar.

O script copia apenas os arquivos do backup (não o pendrive inteiro), verifica o espaço em disco e cria o atalho automaticamente.

Antes de copiar: verifique se há espaço suficiente. Clique na maçã () → Sobre este Mac → Armazenamento para ver o espaço livre.
  1. Abra o Finder (ícone de rosto sorridente no Dock)
  2. No painel esquerdo, clique no nome do pendrive
  3. Selecione todos os arquivos (Cmd+A) e copie (Cmd+C)
  4. No Finder, acesse Documentos. Se já existir uma pasta Backup WhatsApp lá, apague-a primeiro (arraste para a lixeira) para não sobrar arquivos antigos. Depois crie a pasta novamente e cole (Cmd+V) — não cole na área de trabalho, pois o backup pode ter vários GB
  5. Quando terminar, abra a pasta e dê dois cliques em index.html
  6. Para criar um atalho: no Finder, segure Cmd+Alt e arraste o index.html para a área de trabalho
